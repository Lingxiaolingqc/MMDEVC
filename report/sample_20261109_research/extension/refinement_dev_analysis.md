# E4 有限改进尝试：Tokyo dev 独立分析

结论：保留原 E4，不将新候选替换为主方法。预先固定的深度惩罚放宽只产生小幅诊断量变化，未观察到明确视觉收益。

设定：深度 sigma 从 0.1 到 0.2；global 对所有通过硬筛选的区域使用新值；selective 只在 photo<=0.05、FB<=0.5 px 且不在深度边缘扩张带内使用新值。alpha=0.7，其余规则相同。每个方法都使用自己的累积历史，所以边界外仍可能通过历史传播出现微小差异。

|方法|T|与 DA 的归一化差异|参考域平均历史权重|CPU 融合中位秒|
|---|---:|---:|---:|---:|
|original|0.00343925|0.00281687|0.531356|3.412|
|global|0.00335030|0.00310689|0.545878|3.001|
|selective|0.00337224|0.00306866|0.544320|7.630|

定量判断：global / selective 的 T 较原方法分别下降约 2.59% / 1.95%，代价是更偏离当前 DA。可靠内部权重从 0.5579 增至约 0.5728；selective 的边缘带变化远小于 global，但这只是输出变化，不是 GT 误差。selective 当前实现计算两套融合和保护掩码，耗时约为原方法 2.24 倍，不能把代码开销说成算法不可避免的复杂度。

- 六个均匀抽样全景：三种设置的行人轮廓、远景层次和地面渐变相近，未见明确结构改善。
- 28–33 帧：包、外套和腿部轮廓相近，global/selective 与原 E4 的差异很小；没有足够证据称新方法更稳定。
- 73–78 帧包含差异最大帧 75：局部颜色略变，但 76–78 帧头部右侧异常延伸仍存在于三种输出，腿部与地面融合也未解决。
- 已直接检查区域图：严格可靠区域覆盖许多表面内部，边缘带被排除。深度指数通常较小，个别轮廓处较大，不能证明内部历史权重普遍被过度压低。

诊断：可靠内部深度指数均值 0.0590，超过 1 的比例仅约 0.00717%；photo 指数均值 0.1032。深度项在约 25.06% 的可靠内部像素中是最大项，但最大不等于数值很大。原假设没有获得强支持。

检验范围：三次旋转顺序 CPU 计时；数组和权重逐次一致；原 E4 与既有输出完全一致；全部数组、指标及视频时间戳已复算。直接查看六张均匀全景和两个连续 ROI 序列，未进行整段实时播放。无视频深度 GT，T 不是准确率。
