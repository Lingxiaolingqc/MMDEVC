# 自录视频采集清单

主责仍为 B / Jun Yu Eugene YIP；当前由助手实现处理与实验，成员提供真实素材。2026-10-28 已确认尚未录制，下面是待采集方案，不代表已有数据。

## 最小采集方案

先录 8 段，每段约 15 秒，总计约 2 分钟。数量和时长是本项目的工作量选择，不是课程硬性规定。dev 四段用于调试和选参数；test 四段用于冻结参数后的最终评测。每个 test 使用不同房间、位置、背景或明显不同的布置，不能把同一长视频切两半作为 dev/test。场景重复时必须划到同一侧。

| 文件名（建议） | 操作 | 应出现的内容 |
| --- | --- | --- |
| dev_static.mp4 | 手机固定，全程不动 | 桌椅、书本、细椅腿或电线；观察静止场景的预测波动 |
| dev_lateral.mp4 | 手机缓慢左右平移，尽量保持朝向 | 近景物体与远景背景；可在室外包含天空 |
| dev_approach.mp4 | 缓慢靠近目标，再退回 | 椅子、桌子与远处背景；观察真实深度变化时的响应和拖影 |
| dev_occlusion.mp4 | 手机固定，人或物体从前景经过 | 背景被遮挡后重新出现；观察新出现区域 |
| test_static.mp4 | 与 static 同类，换独立场景 | 保持相机与场景不动 |
| test_lateral.mp4 | 与 lateral 同类，换独立场景 | 同时有近、远物体 |
| test_approach.mp4 | 与 approach 同类，换独立场景 | 靠近、停留、退回三个阶段 |
| test_occlusion.mp4 | 与 occlusion 同类，换独立场景 | 遮挡发生前后都留几秒无遮挡画面 |

场景中尽量覆盖玻璃、镜子、天空、细物体。模糊可以取自真实运动片段；若素材没有出现某类要求的失败条件，后续补拍一段约 10 秒的诊断片段，并单独标注用途。不要用人为生成的失败图冒充实拍证据。若只有室内条件，先交室内素材，天空案例后补；采用 indoor checkpoint 时须将室外案例标为域外诊断。

## 手机设置与拍摄

- 横屏 1920×1080、30 fps、普通 SDR 视频即可，使用同一主摄和固定焦段，不用数字变焦。
- 关闭美颜、滤镜和自动镜头切换；设备支持时锁定曝光/对焦。做不到锁定时记录自动曝光，避免把它的影响误判为纯模型抖动。
- static/occlusion 将手机靠稳或固定在支架上；不要用手持画面代替固定相机。
- 相机移动以平稳正常速度为主；前后移动应保留可见的距离变化，不要求测量真实深度。
- 保存原始文件和音视频时间信息。不剪辑、不加速、不插帧，不经过聊天软件压缩。文件名改变可以，内容先保留。

## 放置与交接

建议放在仓库的 `data/videos/raw/`；也可放在其他文件夹后提供绝对路径。该目录不进 Git。只需告诉助手文件夹路径，以及每段视频的拍摄内容、哪些使用同一场景。开发/测试标记在运行模型前固定并写入 `manifests/videos.csv`，缺少或未检查的视频不登记为已完成素材。

助手负责读取帧率/尺寸/实际时间戳、检查解码和场景划分，统一降采样规则，保存原始帧 ID 与时间索引，再执行所有模型。各方法使用完全相同的帧、空间分辨率和固定显示范围。采集阶段无需你先制作深度视频或手动提取图片。

## 验收

- 原视频均能播放，画面内容符合对应类型。
- dev/test 场景组不重叠，最终 test 不参与参数选择。
- 素材覆盖静止、横移、前后移动、动态遮挡以及可定位的困难表面/细结构案例。
- 无真实深度 GT 的视频只用于稳定性、响应、效率及定性分析；不据此报告绝对深度准确率。
