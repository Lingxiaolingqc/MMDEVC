# Residual 与 LoRA 独立选择记录

当前状态：独立选择实验与结果复核完成；两种方法之间的比较留待后续。

## 本次研究问题与范围

分别在预先声明的候选范围内选择 Residual 和 LoRA。Residual 比较特征融合方式、特征阶段数和空间门控；LoRA 比较插入位置、rank 和学习率。此处的“最优”只表示本次候选和开发验证规则下的选择，不是全局最优。

不在本阶段进行两类方法的优劣比较、同样本数量实验、全部 795 张开发数据重训或新的 654 张 test 评测。旧实验、旧冻结决定和旧 test 接触历史保持原样。

## 共用数据与评测

- 使用固定的 577 张 fitting 和 218 张 validation，场景不重叠。GT 只用于训练监督和评测，不作为推理输入。
- 使用同一原始 UniDepthV2 Small 权重、预测相机参数、课程裁剪区域和 0.001–10 m 评测范围；不根据 validation/test GT 对预测做逐图尺度拟合。
- 主选择指标为 image-macro AbsRel。RMSE、delta1、image-macro boundary F1、边界带 AbsRel、参数量和计算成本分别报告。边界 F1 与边界带深度误差回答不同问题，不能互相代替。
- 三次训练种子的标准差反映训练随机性；配对场景 bootstrap 区间反映当前验证场景的抽样变化。二者不是同一种不确定性。所有配对区间均为探索性结果，未做多重比较校正。
- 三种子均值是指标均值，不是三个模型的预测 ensemble。验证集已被反复使用，不能将开发结果描述成新的盲测表现。
- 边界 F1 使用本项目固定诊断：水平或垂直相邻有效像素的 log-depth 绝对差大于 ln(1.1) 定义深度边缘，匹配容差为 2 px，再取逐图 F1 均值；边界带误差在 GT 边缘附近的 2 px 区域统计。它衡量深度不连续处的表现，不是 RGB 纹理边缘分数，也不是另一个官方 NYUv2 主指标。

## Residual 设计

冻结原始 UniDepth，以 RGB、log-depth 和解码器内部特征作为输入，学习 additive depth residual。统一 CNN 主体、AbsRel loss、240×320 修正网格、batch 8、AdamW、学习率 3e-4、最多 80 epochs 和同一早停规则。

| 编号 | 特征阶段 | 融合方式 | 训练种子数 |
|---|---|---|---:|
| S0 | initial | 原有单阶段参考，复用已核验记录 | 3 |
| F2 | initial + late | 投影并统一空间大小后拼接 | 3 |
| F3 | initial + middle + late | 投影并统一空间大小后拼接 | 3 |
| P2 | initial + late | 按原始阶段空间分辨率逐级融合 | 3 |
| P3 | initial + middle + late | 按原始阶段空间分辨率逐级融合 | 3 |
| G2 | initial + late | P2 加空间 sigmoid gate | 3 |
| G3 | initial + middle + late | P3 加空间 sigmoid gate | 3 |
| C2 / C3 | 与 P2 / P3 相同 | 与 P 相同图结构和参数量，提前统一到最终网格 | 各 1 |
| 选中三阶段方案的 zero-middle | 与原方案同图结构 | middle 输入置零，保留参数数量 | 3 |

这里的阶段来自 UniDepth decoder 的 initial latent、middle 和 late 输出，不是任意 ViT 层，也不是对某篇 StyleSketch 方法的复现。两阶段投影通道为 8+8，三阶段为 6+5+5，总投影宽度固定为 16。C2/C3 用于解释空间处理与额外参数的影响，按预先约定不扩展为新的无界候选搜索。zero-middle 将投影前的 middle 特征置零，投影偏置仍可学习；它移除 middle 的图像相关信息，并未删除整个分支。该控制保留名义参数数量，但不等价于保留全部有效功能容量。

选择规则：在 S0 与六个主候选的三种子 mean AbsRel 中选择；相对差距在 0.2% 内时优先参数更少者，再选更低 AbsRel。三阶段方案选中后，完成 zero-middle 对照再冻结。后续训练时长记录为开发阶段最佳 epoch 的中位数。

## LoRA 设计

原始基础模型保持冻结，仅训练 attention 线性层上的 low-rank adapters，输出仍使用官方模型的米制深度路径。保留官方 RGB 预处理、预测相机和深度后处理；零 adapter 必须与原预测数值一致，基础权重在训练前后进行 hash 核验。

搜索为 2 个位置 × 2 个 rank × 2 个学习率，共 8 个配置：

- 位置：decoder attention（包含 CameraHead 与 DepthHead）或 encoder 最后四个 ViT blocks 的 attention。
- rank：4 / 8；学习率：1e-4 / 3e-4；alpha=rank，dropout=0。
- 固定 2,000 次 attempted updates、有效 batch 8、16,000 次图像曝光，每 200 次更新评测一次，选择最佳 validation checkpoint。
- 8 个配置先使用同一 seed320112；验证 AbsRel 最低的两个再各补 seed320113 / 320114。按三种子 mean AbsRel 和相同的 0.2% 简洁性规则冻结，训练时长取最佳 update 的中位数。
- 单种子初筛与三种子确认分开列示，不能将不同种子数的行混为同等强度的证据。AMP 跳过的更新另行计数。
- 两种插入位置包含的 attention 投影数量和可训练参数数不同；这是两个适配目标集合的比较，不能将全部差异单独归因于插入位置。实际目标路径和参数数均保留。

## 工程记录与成本边界

LoRA 正式训练前保留了所有数值预检失败。默认 AMP scale65536 导致相机分支梯度溢出；scale1 的早期小梯度不足；初始 scale128 后，两种位置的五步 batch8 工程预检通过，但该短预检未覆盖真实数据中的数值端点问题。此项是数值可运行性检查，不是使用验证结果选择架构。

首个原协议 LoRA 正式任务随后因相机射线归一化值恰好等于 1、acos 端点反向导数无穷而发生 AMP scale 持续下降，已中止并排除，保留完整失败证据。重新开始的全部 LoRA 候选统一使用 finite_rays_v2：仅训练反向时将 acos 导数分母下限设为浮点精度 epsilon 的平方根；前向值、原始官方代码和无梯度推理均保持不变。这是端点的有界替代梯度。正常 AMP 回退仍保留，scale 低于 1 则中止。新协议先对两种位置、两种 rank 分别执行 200 个不同 fitting 批次预检，权重不用于正式结果。

Residual 的 P2 seed320114 曾因系统可用 CPU 内存不足而中断。原错误记录保留，随后从第 12 个完整 epoch 的 checkpoint 恢复，参数、数据、种子、优化器和数值代码没有改变。训练记录中的累计时长不包含重载过程和未完成 epoch 的全部额外工作，因此不作为严格的运行速度基准。Residual 单独 forward 计时不包含冻结基础模型和特征缓存构建，不能与 LoRA 完整模型 forward 直接比较。

每次训练保留配置、代码快照、数据与权重身份、完整学习曲线、best/final 权重、逐图指标和失败记录。发布记录不包含大数组缓存和模型权重；本地保留的权重有明确路径和 hash。

### 8. 实际图像复核

实际检查了所列定量图、学习曲线，以及 Residual 与 LoRA 各自的匹配 GT/误差/边界图；逐幅清单和 SHA256 见 analysis/visual_review.json。所有匹配图均为 seed320112，三种子均值只用于表格与配对统计，图像不是 ensemble。不是所有生成的案例都经过人工逐幅查看。

- **Residual 相对原单阶段参考 S0：** 固定样例 0598 的大区域误差下降（AbsRel 0.05844→0.04018），但桌椅边界没有全面变锐；0226 的背景深度明显更接近 GT（0.46021→0.21835），枝条等细结构仍有错配。0246 是反例，F3 把背景预测得偏近，误差由 0.08444 升至 0.14330。0080 的整体误差降低，固定边缘判定下却丢失部分架子边缘，F1 从 0.33651 降至 0.09360。
- **融合与门控：** 在共同样例 0598 上，F/P/G 的整体深度图很接近，局部误差和边缘匹配有变化，肉眼不能据此宣布某种融合普遍更好。G3 在 0249 上把远处背景预测得更远，AbsRel 从 P3 的 0.18285 升至 0.22596，说明轮廓相似也可能伴随明显的区域深度退步。
- **控制实验：** 同参数 C2/P2 在 0050 上有小幅收益，在 0249 上有明显退步（0.15628→0.22191）；C3/P3 的固定样例有收益，但不改变单种子控制的证据限制。保留 middle 特征在 0226 上改善人物、柱子和家具深度（0.28689→0.21835），在 0246 上则退步（0.10053→0.14330）。平均收益不是逐图保证。
- **LoRA 相对原始 UniDepth B0：** 0226 的大面积深度高估显著缓解（0.58410→0.17996），但枝条错配仍在。固定样例 0598 几乎不变（0.04813→0.04789），1440 的细椅杆仍然困难。0022 是反例：背景/梯架及部分前景被预测得偏近，AbsRel 从 0.07161 升至 0.15242。0588 的整体误差明显降低（0.07537→0.01653），边缘 F1 却下降，说明两项指标确实衡量不同性质。
- **训练曲线：** decoder 高学习率示例的训练与验证误差同时上升，属于后期优化退化，不能只说“验证集过拟合”。选中的 encoder 配置训练误差继续下降、验证误差进入平台；seed320114 的最佳检查点早至 200 updates，另两次为 1200，完整曲线与末步结果均保留。

以上是对保存产物的观察及其与逐图分数的对应，不把彩色图更平滑、边缘更多或更好看直接当成更准确，也不据此改动已经冻结的选择。
