# CVPR template source

The cvpr.sty and ieeenat_fullname.bst files are copied without modification from the official CVPR author kit at https://github.com/cvpr-org/author-kit. Their authorship and embedded notices remain intact. The report uses the camera-ready style with page numbers, not review line numbering.

The report text, experimental evidence, and figures are independently authored for this project. Numerical macros and the ablation table are generated from saved measured JSON files by scripts/write_report_values.py; figures are regenerated by scripts/make_figures.py.

The author line uses the configured Git display name, Eugene, as an independent draft. Confirm the final author names before submitting the group report. The source-length compliance warning must remain until a longer official clip or TA clarification resolves it.
